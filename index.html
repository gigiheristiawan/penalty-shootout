How this was built

A first-person penalty shootout, written to learn 3D on the web rather than to ship a product. No game engine and no React Three Fiber — the point was to see what those abstract away.

  • Three.js, used directly: scene graph, one directional light plus ambient, flat-shaded primitives.
  • cannon-es for physics, on a fixed 60 Hz timestep decoupled from the render loop. Bodies own position; meshes are copied from them every frame.
  • Everything is at real-world scale — 7.32×2.44 m goal, 11 m spot, a 0.43 kg ball — so gravity feels right.
  • The kick is a single impulse, with an explicit correction for the metre the ball drops on its way to the goal.
  • Curve is a constant sideways force, not real Magnus. Real curve depends on spin; at penalty distance nobody can tell.
  • Goal detection is a sensor volume behind the line, not a position check — a 30 m/s shot moves half a metre per tick and would tunnel straight through a plane test.
  • Sound is synthesised with the Web Audio API. Zero bytes shipped, no licences to track.
